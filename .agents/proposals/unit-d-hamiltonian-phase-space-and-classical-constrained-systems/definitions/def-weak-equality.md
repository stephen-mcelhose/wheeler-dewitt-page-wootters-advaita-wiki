# Weak Equality

\(F\approx G\) means that \(F-G\) vanishes on the constraint surface; it is not an identity on the full phase space. In particular, take Poisson brackets before using a weak equality unless a justified reduced construction has been made.

Learn more: [Classical Constrained Systems](../mathematics/constrained-systems.md).

# Gauge Fixing

Gauge fixing adds conditions chosen to intersect nearby gauge orbits once, thereby selecting representatives. Such a condition can fail globally by missing or meeting an orbit more than once, so it is not automatically a global physical clock.

Learn more: [Classical Constrained Systems](../mathematics/constrained-systems.md).

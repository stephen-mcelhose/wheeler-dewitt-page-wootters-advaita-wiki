# Total Hamiltonian

The total Hamiltonian is \(H_T=H_{\rm can}+\lambda^a\phi_a\), adding primary constraints \(\phi_a\) with multiplier functions \(\lambda^a\). Consistency can constrain multipliers or yield additional constraints; this formula alone is not a completed constraint analysis.

Learn more: [Classical Constrained Systems](../mathematics/constrained-systems.md).

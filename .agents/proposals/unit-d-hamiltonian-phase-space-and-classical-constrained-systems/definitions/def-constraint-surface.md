# Constraint Surface

For constraints \(\phi_a\), the constraint surface is \(\Gamma=\{(q,p):\phi_a(q,p)=0\ \text{for all }a\}\). Weak equality refers to equality only after restriction to this surface.

Learn more: [Classical Constrained Systems](../mathematics/constrained-systems.md).

Phase space is the classical state space whose local canonical coordinates are \((q^i,p_i)\): configuration coordinates and their conjugate momenta. A point gives a complete instantaneous state for the specified Hamiltonian model, not merely a configuration.

# Poisson Bracket

In local canonical coordinates, \(\{F,G\}=\sum_i(\partial F/\partial q^i\,\partial G/\partial p_i-\partial F/\partial p_i\,\partial G/\partial q^i)\). It is a classical operation: it is neither an inner product nor, without further quantization assumptions, a quantum commutator.

Learn more: [Hamiltonian Phase Space and Poisson Brackets](../mathematics/hamiltonian-phase-space-and-poisson-brackets.md).

# Hamiltonian

A Hamiltonian \(H(q,p,t)\) is a phase-space function that, in a regular external-time canonical model, gives \(\dot q^i=\partial H/\partial p_i\) and \(\dot p_i=-\partial H/\partial q^i\). It is not automatically the physical energy or the generator of physical time evolution in a constrained system.

Learn more: [Classical Canonical Mechanics Primer](../mathematics/classical-canonical-mechanics-primer.md).
```

# Hamiltonian Flow

The Hamiltonian flow of \(H\) is the integral curve satisfying \(dF/dt=\{F,H\}+\partial F/\partial t\) in an external-time model. A constraint can also generate a bracket flow, but that curve may be gauge flow rather than external-time evolution.

# Constraint

A constraint is a condition \(\phi(q,p)\approx0\) imposed on phase space. The allowed points form a constraint surface; Poisson brackets with the full constraint set determine whether the constraints are first class or second class.

# First-Class Constraint

A constraint \(\phi_a\) is first class when \(\{\phi_a,\phi_b\}\approx0\) for every constraint in the chosen set (or the brackets close into constraints). Under standard regularity and complete-generator assumptions, first-class combinations generate gauge transformations; the classification alone is not a global gauge theorem.

Learn more: [Classical Constrained Systems](../mathematics/constrained-systems.md).
```

# Second-Class Constraint

A set \(\chi_a\) is second class when \(C_{ab}=\{\chi_a,\chi_b\}\) is invertible on the constraint surface. Such constraints are normally solved or handled with a Dirac bracket; they do not represent gauge redundancy in the same way as first-class constraints.

# Self-Adjoint Operator

A densely defined operator \(A\) is self-adjoint when \(A=A^*\), meaning both \(D(A)=D(A^*)\) and \(A\psi=A^*\psi\) for every \(\psi\) in that common domain. This is stronger than symmetry; for unbounded operators, equality of formal differential expressions is not enough.

Learn more: [Operators, Domains, and Self-Adjointness](../mathematics/operators-and-domains.md).

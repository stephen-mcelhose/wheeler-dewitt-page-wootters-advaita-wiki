# Symmetric Operator

A densely defined operator \(A\) is symmetric when \(\langle\phi|A\psi\rangle=\langle A\phi|\psi\rangle\) for all \(\phi,\psi\in D(A)\). Equivalently, \(A\subset A^*\): the adjoint can have a larger domain. Symmetry alone therefore does not imply self-adjointness.

Learn more: [Operators, Domains, and Self-Adjointness](../mathematics/operators-and-domains.md).

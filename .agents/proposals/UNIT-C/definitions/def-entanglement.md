# Entanglement (Pure Bipartite State)

Relative to a specified factorization \(\mathcal H_A\otimes\mathcal H_B\), a pure state is entangled when it cannot be written \(|a\rangle\otimes|b\rangle\). The definition for mixed-state entanglement is more general and requires separability language.

Learn more: [Composite Quantum Systems](../mathematics/composite-systems.md).

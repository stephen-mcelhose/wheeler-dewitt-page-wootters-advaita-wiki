# Density Operator

A density operator \(\rho\) is positive semidefinite and has \(\operatorname{Tr}(\rho)=1\). A normalized pure vector \(|\psi\rangle\) gives \(\rho=|\psi\rangle\langle\psi|\); density operators also describe statistical mixtures.

Learn more: [Composite Quantum Systems](../mathematics/composite-systems.md).

# Reduced State

For a joint state \(\rho_{CS}\), the reduced state of \(S\) is \(\rho_S=\operatorname{Tr}_C(\rho_{CS})\). It gives statistics of observables on \(S\) when \(C\) is ignored; no outcome is selected and no measurement update is specified.

Learn more: [Composite Quantum Systems](../mathematics/composite-systems.md).

# Partial Trace

For \(\rho_{CS}\), \(\operatorname{Tr}_C(\rho_{CS})\) is the unique operator on \(S\) whose expectation values agree with those of \(\rho_{CS}\) for every system-only observable \(I_C\otimes A_S\). It discards the \(C\) factor without selecting an outcome.

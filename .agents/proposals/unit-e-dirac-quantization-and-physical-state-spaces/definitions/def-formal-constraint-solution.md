# Formal Constraint Solution

A formal constraint solution satisfies equations such as \(\hat C_I\Psi=0\) with the relevant domains or distributional extension stated. It need not be an ordinary kinematical Hilbert-space vector or already carry the physical inner product.

Learn more: [Dirac Quantization and Physical States](../mathematics/dirac-quantization.md).

# Measurement Effect

An effect \(E\) satisfies \(0\leq E\leq I\); in state \(\rho\), it gives probability \(\operatorname{Tr}(E\rho)\). An effect supplies statistics, not a selective state-update rule.

Learn more: [Measurements and Conditional States](../mathematics/conditional-states.md).

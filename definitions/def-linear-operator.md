# Linear Operator

Let \(D(A)\) be a linear subspace of a complex vector space \(\mathcal H\). A linear operator \(A:D(A)\to\mathcal H\) satisfies \(A(\alpha\psi+\beta\phi)=\alpha A\psi+\beta A\phi\) whenever \(\phi,\psi\in D(A)\) and \(\alpha,\beta\in\mathbb C\). The stated domain is part of the operator.

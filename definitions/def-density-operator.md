# Density Operator

A density operator \(\rho\) is positive semidefinite with \(\operatorname{Tr}(\rho)=1\). It represents a pure state when \(\rho=|\psi\rangle\langle\psi|\), and can also represent a mixture.

Learn more: [Composite Quantum Systems](../mathematics/composite-systems.md).

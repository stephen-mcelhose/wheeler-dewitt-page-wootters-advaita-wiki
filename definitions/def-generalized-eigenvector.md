# Generalized Eigenvector

A distributional object used in continuous-spectrum notation that formally obeys an eigenvalue equation but is generally not a normalizable vector in the Hilbert space. Unlike an ordinary eigenvector, it need not be an element of the Hilbert space itself.

Learn more: [Spectral Notation](../mathematics/spectral-notation.md).

# Functional Derivative

A functional derivative \(\delta F/\delta h_{ab}(x)\) describes the change of a functional when the field configuration \(h_{ab}(x)\) is varied locally.

Learn more: [Wheeler–DeWitt Formalism](../physics/wheeler-dewitt-formalism.md).

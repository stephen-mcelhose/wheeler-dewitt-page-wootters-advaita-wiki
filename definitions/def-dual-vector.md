# Dual vector

A dual vector is a continuous linear functional on a Hilbert space; the inner product associates one with each vector. With the convention used here, the associated bra is linear in the vector to its right. In coordinates relative to an orthonormal basis, the bra associated with a ket is written by taking the ket's conjugate transpose (Hermitian adjoint); this coordinate operation should not be confused with the abstract dual vector itself.

Learn more: [Dirac Notation](../mathematics/dirac-notation.md).

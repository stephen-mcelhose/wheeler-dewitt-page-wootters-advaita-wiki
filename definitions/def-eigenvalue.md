# Eigenvalue

If an operator \(\hat A\) acts on a nonzero vector \(|a\rangle\) by \(\hat A|a\rangle=a|a\rangle\), then \(a\) is the eigenvalue associated with that eigenvector.

Learn more: [Spectra and Generalized Bases](../mathematics/spectral-notation.md).

# Reduced State

For a joint state \(\rho_{CS}\), the reduced state of \(S\) is \(\rho_S=\operatorname{Tr}_C(\rho_{CS})\). It describes system-only statistics with \(C\) ignored, not a state conditioned on an outcome.

Learn more: [Composite Quantum Systems](../mathematics/composite-systems.md).

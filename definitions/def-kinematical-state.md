# Kinematical State

A kinematical state belongs to the auxiliary space \(\mathcal H_{\mathrm{kin}}\) before solving quantum constraints and constructing the physical inner product.

Learn more: [Dirac Quantization](../mathematics/dirac-quantization.md).

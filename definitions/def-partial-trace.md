# Partial Trace

\(\operatorname{Tr}_C(\rho_{CS})\) is the unique system operator reproducing \(\rho_{CS}\)'s statistics for observables acting only on \(S\). It discards \(C\); it does not select a measurement outcome.

Learn more: [Composite Quantum Systems](../mathematics/composite-systems.md).

# Conditional State

In this finite measurement setting, a conditional state is the normalized system state associated with a declared effect and a positive outcome probability. It is distinct from the unconditioned reduced state and does not alone specify a joint selective update.

Learn more: [Measurements and Conditional States](../mathematics/conditional-states.md).

# Second-Class Constraint

A set \(\chi_a\) is second class when \(C_{ab}=\{\chi_a,\chi_b\}\) is invertible on the constraint surface. Such constraints are normally solved or handled with a Dirac bracket; they do not represent gauge redundancy in the same way as first-class constraints.

Learn more: [Classical Constrained Systems](../mathematics/constrained-systems.md).

# Physical State

A physical state is a solution of the quantum constraints in the appropriate physical construction; it may be distributional rather than an ordinary vector in \(\mathcal H_{\mathrm{kin}}\).

Learn more: [Dirac Quantization](../mathematics/dirac-quantization.md).

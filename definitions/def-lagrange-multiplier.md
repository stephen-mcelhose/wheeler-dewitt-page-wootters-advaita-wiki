# Lagrange Multiplier

A Lagrange multiplier is an auxiliary variable or function used to impose a constraint. In \(H_T=H_{\rm can}+\lambda^a\phi_a\), \(\lambda^a\) enforces primary constraints and may be partly fixed by consistency; it is not automatically a physical observable or a time parameter.

Learn more: [Classical Constrained Systems](../mathematics/constrained-systems.md).

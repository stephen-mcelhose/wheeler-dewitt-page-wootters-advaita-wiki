# Kronecker delta

The Kronecker delta \(\delta_{nm}\) equals \(1\) if \(n=m\) and \(0\) otherwise. It expresses orthonormality for a discrete basis.

Learn more: [Dirac Notation](../mathematics/dirac-notation.md).

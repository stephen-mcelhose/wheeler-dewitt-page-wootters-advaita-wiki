# Constrained History State

A constrained history state is a selected clock-system state whose branches correlate clock and system degrees of freedom while satisfying a declared global constraint such as \(\hat C|\Psi\rangle=0\). In finite models it can be an ordinary normalized vector; in idealized continuous models it can instead be formal or generalized.

Learn more: [Constrained Clock–System Models](../page-wootters/constrained-clock-system-models.md).

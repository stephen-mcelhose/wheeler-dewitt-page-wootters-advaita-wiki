# Hamiltonian Constraint

In ADM gravity, the Hamiltonian constraint is the local scalar condition \(\mathcal H_\perp(x)\approx0\) on each spatial point. Together with the momentum constraints, it restricts admissible canonical data; it is associated with normal hypersurface deformations in the stated classical regime.

Learn more: [Hamiltonian and Momentum Constraints](../physics/adm-constraints.md).

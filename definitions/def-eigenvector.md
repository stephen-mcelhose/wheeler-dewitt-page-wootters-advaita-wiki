# Eigenvector

A nonzero vector \(|a\rangle\) is an eigenvector of \(\hat A\) with eigenvalue \(a\) when \(\hat A|a\rangle=a|a\rangle\). The operator preserves the vector’s direction while multiplying it by the scalar \(a\).

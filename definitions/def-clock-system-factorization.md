# Clock/System Factorization

A clock/system factorization writes a model space as \(\mathcal H_C\widehat\otimes\mathcal H_S\). It is a modeling choice and can be nonunique or unavailable in constrained systems.

Learn more: [Page Wootters Mechanism](../page-wootters/page-wootters-mechanism.md).

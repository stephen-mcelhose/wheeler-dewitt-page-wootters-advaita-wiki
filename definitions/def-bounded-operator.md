# Bounded Operator

A linear operator \(A:\mathcal H\to\mathcal H\) is bounded when there is a finite constant \(C\) such that \(\|A\psi\|\le C\|\psi\|\) for every \(\psi\in\mathcal H\). In the usual Hilbert-space convention, a bounded operator is defined on all of \(\mathcal H\); a norm bound only on a smaller domain should be stated with that domain.

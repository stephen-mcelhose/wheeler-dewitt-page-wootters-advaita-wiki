# Ideal Clock State Family

An ideal clock state family is a generalized set of labels \(|t\rangle\) with a formal covariance relation to the clock Hamiltonian. It is used in ideal Page–Wootters derivations and need not consist of ordinary normalized Hilbert-space vectors.

Learn more: [Clock States and Sign Convention](../page-wootters/clock-states.md).

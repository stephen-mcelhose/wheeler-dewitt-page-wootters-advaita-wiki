# Born rule

For a normalized pure state \(|\psi\rangle\) and an orthogonal projector \(P\) representing the yes outcome of an ideal sharp projective measurement, the Born rule assigns

\[
p_{\mathrm{yes}}=\langle\psi|P|\psi\rangle.
\]

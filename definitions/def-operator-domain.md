# Operator Domain

For an operator \(A\), \(D(A)\) is the stated linear subset of \(\mathcal H\) on which \(A\) acts. The pair consisting of the action rule and \(D(A)\), not the formal rule alone, specifies the operator; an unbounded operator generally has \(D(A)\ne\mathcal H\).
